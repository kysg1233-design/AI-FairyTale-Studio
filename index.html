🎙️ 한국어 나레이션 · 필수

Gemini가 컷별 대본을 읽어 줍니다. 나레이션 없이 완성하는 기능은 제공하지 않습니다.

GitHub Actions 서버에서 합성합니다. 원본 영상 화질보다 높아지지는 않습니다.

한국어 자막은 필수로 삽입됩니다. 현재 서버 자막은 문장 길이에 따른 시간 배분이며 실제 발음 단위 노래방 강조는 아직 제공하지 않습니다.

내레이션 음량은 합성 시 반영됩니다. 과도한 음량은 자동 제한합니다.

말소리 없이 생성한 Veo 원본의 효과음·배경음을 자동으로 낮게 합성합니다. 화면이 반복돼도 원본 소리는 컷마다 한 번만 사용합니다. Veo가 예상과 달리 대사를 생성한 영상은 그 대사도 함께 들어갈 수 있으니, 그런 경우 배경음 크기를 ‘끄기’로 바꾸세요.

대사를 줄이거나 음성을 자르지 않습니다. 원본 영상이 끝나도 나레이션이 계속되면 마지막 화면만 연장합니다. 생성 음성은 Gemini TTS 사용량에 포함됩니다.

✦ 최종 MP4는 GitHub 비공개 저장소에 업로드하고 GitHub Actions에서 합성합니다. Cloudflare 등 다른 서비스는 사용하지 않습니다. 업로드가 끝나면 크롬을 닫아도 됩니다. GitHub 토큰과 비공개 저장소의 Gemini Actions secret은 필요합니다. 컷당 최대 50MiB입니다.
